# Financial Advisor

A machine learning-powered financial profiling and advisory web application built using Flask.

## Overview

The application collects a user's age, income, expenses, and savings and uses a K-Means clustering model to identify their financial profile.

Users can compare their financial statistics against their cluster's median values and receive personalized financial guidance through an AI-powered chatbot.

## Features

- Financial data input and validation
- K-Means financial profiling
- Five financial profile categories
- Comparison with cluster median statistics
- Savings rate and expense ratio analysis
- AI-generated financial guidance
- Follow-up financial chatbot
- Conversation history
- Flask session management
- Responsive web interface

## Technologies Used

- Python
- Flask
- Pandas
- Scikit-learn
- K-Means Clustering
- Google Gemini API
- HTML
- CSS
- JavaScript

## How It Works

1. The user enters their age, income, expenses, and savings.
2. The data is standardized using StandardScaler.
3. A trained K-Means model assigns the user to one of five financial clusters.
4. The application displays the user's financial profile and compares their statistics with the cluster median.
5. Financial information is provided to Gemini to generate personalized educational guidance.
6. The user can continue the conversation through the financial advisor chatbot.

## Financial Profiles

The model groups users into five profiles:

- High Income Balanced
- High Income High Spender
- Moderate Income Saver
- Financially Strained
- Wealth Builder

## Security

API keys are stored using environment variables and are excluded from version control using `.gitignore`.
